# Журнал изменений

Версии — [SemVer](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`, номер сборки
после `+` в `pubspec.yaml` растёт с каждой тестовой сборкой. Версия задана в трёх
местах — `pubspec.yaml`, `AppConfig.version` и этот файл; их согласованность
проверяет `test/version_test.dart`. Релиз помечается git-тегом `vX.Y.Z`.

## [0.0.7] — 2026-10-28

### Изменено
- При запуске сразу показывается экран «Запуск…» с текущим шагом, а при сбое
  инициализации — текст ошибки. Раньше приложение на iPhone оставалось на
  белом экране без объяснений, пока main() не доходил до runApp.

## [0.0.6] — 2026-10-28

### Исправлено
- Ссылка из письма, которая не сработала (устарела, уже использована, открыта
  не в том приложении), больше не «молчит»: приложение показывает сообщение
  с причиной. Раньше ошибка Supabase терялась, и казалось, что ссылка не
  открывается.

## [0.0.5] — 2026-10-28

### Исправлено
- Регистрация на уже занятую почту больше не выглядит успешной: Supabase в этом
  случае не шлёт письмо и отвечает «успехом», теперь приложение показывает
  «Эта почта уже зарегистрирована — войди или восстанови пароль».

## [0.0.4] — 2026-10-28

### Изменено
- Запуск без ключей Supabase убран: вместо мок-режима приложение показывает
  экран «Нет ключей Supabase» с командой запуска. Моки остались только для
  тестов.

### Добавлено
- `run.sh` — запуск с `dart_defines.json` (`./run.sh macos`).

## [0.0.3] — 2026-10-28

### Добавлено
- Восстановление пароля до конца: ссылка из письма возвращает в приложение
  (URL-схема `com.fonsski.amessenger://reset-password` на iOS, macOS и Android,
  адрес сайта в вебе), открывается экран «Новый пароль», после сохранения
  пользователь остаётся в аккаунте. В демо-режиме без Supabase «письмо» с
  ссылкой «приходит» само через ~5 секунд.

### Нужно на стороне Supabase
- Authentication → URL Configuration → Redirect URLs: добавить
  `com.fonsski.amessenger://reset-password` (сделано в проекте A-bd).
- Authentication → Emails → SMTP Settings: подключить свой SMTP. Со встроенной
  почтой письма доходят только членам команды проекта и только в малом
  количестве, обычным пользователям — нет.

### Не охвачено
- Windows и Linux: обработки ссылок нет, там redirect не задаётся и ссылка
  открывается в браузере на Site URL.
- Просроченная ссылка: сообщение об ошибке при возврате в приложение не
  показывается.

## [0.0.2] — 2026-10-28

### Исправлено
- Восстановление доступа: ошибка отправки письма (лимит писем Supabase, запрет
  встроенной почты для чужих адресов) терялась молча — теперь показывается.
- Подпись ссылки «Восстановить доступ?» содержала латинскую `c` вместо русской.

### Известно
- Ссылка из письма пока не ведёт в приложение (исправлено в 0.0.3).

## [0.0.1] — 2026-10-27

Первая версионированная сборка (до этого версии не было: `1.0.0+1` из шаблона).

### Есть в приложении
- Вход и регистрация по почте, выбор @ника, вход по QR, код-замок.
- Чаты 1:1: фото/видео/файлы, ответы, закрепы, реакции, поиск, удаление
  у себя и у всех, голосовые сообщения и видеокружки, звонки (WebRTC).
- Галочки прочтения «А» / «АА» (нужна миграция `supabase/fix_020_read_receipts.sql`).
- Стенка: посты, комментарии с ветками, дизлайки, репосты.
- Друзья, чёрный список, приватность.
- Настройки: тема, размер шрифта, фон чатов, автозагрузка фото, память, FAQ.

### Платформы
- Web, Windows, Android (сборка APK не проверялась).
- iOS и macOS: добавлены платформы для отладочных сборок на своих устройствах.

### Известные ограничения
- Звонки только через STUN (нет TURN), уведомлений о входящем в фоне нет.
- Системные уведомления только в веб-версии.
- Групповых чатов, стикеров, пересылки пока нет.
